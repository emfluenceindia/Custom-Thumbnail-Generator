Custom Thumbnail Generator is a free WordPress plugin that lets you create thumbnails and access them throughout the project, even on theme changes.

== Description ==

Custom Thumbnail Generator (CTG) lets you define and manage multiple image sizes for your WordPress media library and your theme. With an intuitive AJAX-powered interface, you can add, remove, and regenerate thumbnails without refreshing the page. The most interedting feature is the thumbnails you register through this plguin, remain accessible throughout the project even on theme changes. Ideal for developers, photographers, and content creators who need precise control over image dimensions.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate the plugin via the **Plugins** menu in WordPress.
3. Go to **Settings > Custom Thumbnail Generator** to configure your image sizes.

== Frequently Asked Questions ==

= Will this delete existing thumbnails? =
No. Removing a size only prevents future generation. Existing files remain untouched.

= Does it support multisite? =
Yes, activate network-wide to manage thumbnails across subsites.
