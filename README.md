The plugin lets you create theme-independent thumbnail sizes

== Description ==

With the Custom Thumbnail Generator plugin, you can add or remove different custom image sizes and store them in a database using a user interface. These image sizes are completely independent of theme and will be available as ling as the plugin remains active. 
In addition to the core and theme-defined thumbnail sizes, these custom size thumbnails will automatically be generated  Whenever an image is uploaded. Moreover, you can also regenerate thumbnails for existing images and generate new thumbnail sizes without installing any other plugin.
