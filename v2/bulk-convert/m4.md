## Feature acceptance checklist

The completed feature must:

- Convert existing JPEG/JPG, PNG, and GIF thumbnail files to WebP using WordPress's supported image editor, with clear handling when WebP output is unavailable.
- Provide one bulk conversion action covering all existing supported thumbnail sizes across eligible image attachments, plus an action for each displayed registered size (core, theme, and plugin-custom) that converts only that size across attachments.
- Process work in bounded requests and show accurate real-time progress, counts, and a truthful completion/partial-failure summary.
- Preserve original attachments and source thumbnail files. WebP outputs remain separate sidecar derivatives. Do not silently rewrite attachment metadata, original URLs, or original formats.
- Preserve existing regeneration, add-size, and remove-size behavior. Conversion actions must remain distinct from regeneration.
- Be secure, capability-restricted, nonce-protected, robust to missing/corrupt files and partial failures, and follow the M1 collision/retry policy.
